# GrowX AI Gateway — Usage & Spend Analytics UX Specification (D7)

## 1. Executive Summary & Objective

The Usage & Spend Analytics dashboard (`/[organizationSlug]/[workspaceSlug]/usage`) gives workspace administrators, engineers, and finance teams a single authoritative view of consumption, spend, latency distributions, and error taxonomies. All analytics are powered by the Phase-14 Analytics Projection Engine and Phase-16 Settled Financials.

---

## 2. Core Metrics & Definitions

1. **Total Requests**: Count of all incoming gateway requests within the selected time window.
   - **Success Rate**: Percentage of completed requests (`completed / total * 100`).
   - **Error Rate**: Percentage of failed requests (`failed / total * 100`).
2. **Token Consumption**:
   - **Input Tokens**: Prompt tokens submitted to upstream providers.
   - **Output Tokens**: Completion tokens returned by upstream providers.
   - **Cached Input Tokens**: Prompt tokens served from Exact or Semantic cache.
   - **Reasoning Tokens**: Internal reasoning/thinking tokens emitted by reasoning models.
3. **Modality-Specific Units**:
   - **Text / Chat**: Count of tokens (input + output).
   - **Vision / Images**: Count of image units processed.
   - **Audio / Speech**: Total seconds of audio transcribed or synthesized.
   - **Embeddings**: Count of embedding tokens and vector items generated.
4. **Authoritative Settled Spend**: Total financial cost in USD computed at execution time using immutable Phase-16 pricing snapshots.
5. **Latency Percentiles**:
   - **P50 (Median)**: 50th percentile of execution duration.
   - **P95**: 95th percentile of execution duration.
   - **P99**: 99th percentile of execution duration.
   - **TTFT (Time to First Token)**: Median time in milliseconds before the first streaming byte is delivered to the client.

## 3. Visualizations & Visual Hierarchy

- **Obsidian × Ice × Frost Palette**: Deep obsidian surface canvases with sharp ice cyan (`#5eead4`) and frosted aqua (`#8be9fd`) accents.
- **Velocity SVG Area Chart**: Hourly request volume and upstream failure frequency with clean gradient fills and gridlines.
- **Consumption SVG Area Chart**: Token volume and settled spend accumulation over time.
- **Modality Strip**: Compact summary pill bar displaying consumption across Text, Vision, Audio, and Embeddings.

---

## 4. Breakdown & Drilldown Views

1. **Model Breakdown Table**:
   - Model Name & Canonical ID
   - Provider / Family badge
   - Routed Requests count and traffic share percentage
   - Total Tokens consumed
   - Settled Spend in USD
   - P95 Latency (ms)
   - Success Rate (%)
2. **API Key Breakdown Table**:
   - API Key Name & Masked Prefix (e.g. `gx_live_key_••••••••••••`)
   - Requests and Tokens generated by that key
   - Settled Spend
   - Last Used Timestamp
3. **Error Breakdown Table**:
   - Canonical Error Category (`Rate Limits`, `Timeouts`, `Provider Internal`, `Policy Denials`)
   - Error Code badge (`rate_limit_exceeded`, `upstream_timeout`, etc.)
   - Occurrences and share percentage
   - Clear diagnostic description

---

## 5. Freshness & Invariants

- **Data Freshness Indicator**: Real-time indicator displaying projection lag (e.g. `Projected 30s ago`).
- **No Provider Internal Leakage**: Upstream provider internal scoring, private account IDs, and routing engine heuristics remain strictly protected on the privileged plane.
- **Multi-Tenant Scoping**: All aggregate queries are strictly scoped to the active organization and workspace.
